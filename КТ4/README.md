Что делает скрипт

Загружает исходный Parquet-файл source.parquet.

Округляет время прибытия ARR_TIME до целого (ARR_TIME_ROUNDED).

Классифицирует записи по временам дня в новую колонку CATEGORY:

(-∞, 12] → morning

(12, 18] → afternoon

(18, +∞) → evening

Сохраняет отдельный Parquet-файл на локальный диск для каждой категории.

Копирует файлы в контейнер Hadoop (docker cp), затем загружает их в HDFS (hdfs dfs -put).

(Опционально) Агрегирует статистику по категориям (кол-во строк и пример даты).
